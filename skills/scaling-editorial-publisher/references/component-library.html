Demo: Wie ein redaktionelles Thema Schritt für Schritt verständlich aufbereitet wird

Dieser ausschließlich zu Gestaltungszwecken erstellte Demoartikel zeigt, wie Headline, Titelbild, Zwischenüberschriften, Quellen und eine ergänzende Sidebar zusammenspielen.

Elisabeth König

Expertin für Immobilien

Veröffentlicht: noch festzulegen · Aktualisiert: 02.11.2026

Lesezeit: 3 Minuten

Demo-Hinweis: Der folgende Inhalt ist neutraler Beispieltext. Er beschreibt keine realen Ereignisse, Personen, Marktdaten oder journalistischen Erkenntnisse.

Eine gute Artikelseite gibt dem Inhalt eine klare Reihenfolge und lässt Leserinnen und Leser ohne Ablenkung durch den Text gehen. Am Anfang steht eine eindeutige Rubrik. Darunter fassen Headline und Subline das Thema so zusammen, dass bereits vor dem ersten Absatz erkennbar wird, worum es im Beitrag geht. Das große Bild schafft anschließend eine visuelle Pause, bevor der eigentliche Text beginnt. In dieser Vorlage sind alle Teile bewusst zurückhaltend gestaltet, damit später sehr unterschiedliche redaktionelle Inhalte in derselben Struktur funktionieren können.

Eine klare Struktur führt durch den Beitrag

Der Fließtext verwendet eine schmalere Spalte als das umgebende Seitenlayout. Dadurch bleiben die Zeilen auch auf großen Bildschirmen angenehm kurz. Absätze gliedern jeweils einen Gedanken, während Zwischenüberschriften einen neuen Abschnitt ankündigen. Diese Ordnung ist nicht an eine feste Textlänge gebunden. Ein kurzer Beitrag kann mit wenigen Absätzen auskommen; ein längerer Beitrag darf weitere Absätze und Überschriften enthalten, ohne dass dafür das grundsätzliche Layout verändert werden muss.

Auch die visuelle Gewichtung bleibt eindeutig. Die Hauptüberschrift ist das stärkste Textelement. Eine Überschrift der zweiten Ebene teilt den Artikel in größere Kapitel. Falls innerhalb eines Kapitels eine weitere Unterteilung hilfreich ist, kann eine dritte Ebene eingesetzt werden. Die semantische Reihenfolge bleibt dabei erhalten und unterstützt sowohl die Orientierung als auch die barrierearme Nutzung.

Unterpunkte bleiben Teil desselben Abschnitts

Eine kleinere Zwischenüberschrift eignet sich für einen klar abgegrenzten Unterpunkt. Sie soll nicht nur aus gestalterischen Gründen verwendet werden, sondern eine echte inhaltliche Unterteilung markieren. Danach kann der Text normal weiterlaufen. Auf diese Weise bleibt die Seite auch dann verständlich, wenn ein Beitrag mehrere Aspekte nacheinander behandelt.

Bild und Text reagieren auf die verfügbare Breite

Das Titelbild verwendet ein festes Seitenverhältnis von sechzehn zu neun und passt sich der verfügbaren Breite an. Auf kleineren Bildschirmen wird es gemeinsam mit der Textspalte verkleinert. Ein später geliefertes redaktionelles Bild kann den neutralen Platzhalter direkt ersetzen. Wenn das Bild eigenständige Informationen vermittelt, braucht es eine passende Bildbeschreibung.

Die Abstände folgen einem wiederkehrenden Rhythmus: Eng zusammengehörige Elemente stehen näher beieinander, neue Abschnitte erhalten mehr Raum. Auf Mobilgeräten werden diese Abstände kompakter. Die ergänzende Sidebar folgt unterhalb des Artikels, sobald das gemeinsame Portalgrid auf eine Spalte wechselt.

Quellen schließen den Artikel ruhig ab

Am Ende steht ein eigener Quellenbereich. Er trennt redaktionellen Text klar von weiterführenden Nachweisen. Dieser interne Demoartikel verwendet den ausdrücklich freigegebenen nicht verlinkten Quellenhinweis und ist nicht zur Veröffentlichung bestimmt.

Quellen schließen den Artikel ruhig ab

Am Ende steht ein eigener Quellenbereich. Er kann einen oder mehrere Einträge aufnehmen und trennt redaktionellen Text klar von weiterführenden Nachweisen. Für diese Vorschau werden ausschließlich erkennbare Platzhalter verwendet. Bei einem echten Artikel werden Quellennamen und vollständige, geprüfte URLs aus dem Writer Package übernommen. Damit ist die Struktur für den späteren Einsatz vorbereitet, ohne im Beispiel Tatsachen oder vermeintliche Belege zu erfinden. Die klare Trennung erleichtert außerdem die spätere Prüfung: Redaktion und Technik können Inhalt, Linkziele und Darstellung nacheinander kontrollieren, ohne das Layout für jeden Beitrag neu zusammensetzen zu müssen.
